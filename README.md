# 🌯 Фрито Буррито (Frito Burrito) — Доставка мексиканской кухни

Тестовая версия сайта и системы доставки для кафе быстрого питания **«Фрито Буррито»** (Краснодар, ул. им. Петра Метальникова, 3/1А).

Интерфейс и пользовательский путь спроектированы в дизайн-системе **Яндекс Еды**: чистый, светлый, контрастный, аппетитный дизайн без «ИИ-слопа» и визуального шума.

---

## 🎯 Ключевые возможности

1. **Дизайн в стиле Яндекс Еды (Human-First & Product-First)**:
   - Шапка с выбором адреса доставки («Краснодар, ул. Петра Метальникова, 3/1А»), поиском по меню и переключателем «Доставка / Самовывоз».
   - Баннер заведения с реальными метриками: **★ 5.0** (240+ отзывов на Яндекс Картах), время доставки 25–35 мин, бесплатная доставка от 800 ₽.
   - Ссылка на реальную карточку на [Яндекс Картах](https://yandex.ru/maps/org/frito_burrito/201782394789/).
   - Информационное модальное окно «О заведении» (режим работы с 10:00 до 23:00, зона доставки, телефон +7 (999) 650-55-76).

2. **Интерактивное меню с рубрикатором (Sticky Tabs)**:
   - Категории: *🔥 Популярное*, *🌯 Буррито*, *🌮 Тако и Кесадильи*, *🍟 Горячие закуски*, *🥑 Фирменные соусы*, *🥤 Напитки*, *🎁 Комбо*.
   - Плавная прокрутка, горизонтальный скролл табов и автоматический ScrollSpy (активная категория подсвечивается при скролле).
   - Мгновенный поиск по названиям и составу блюд.

3. **Карточки блюд и кастомизация (Модификаторы)**:
   - В 1 клик добавление в корзину базового варианта блюда прямо из каталога.
   - Степпер `[ − ] [ 1 ] [ + ]` прямо на карточке при повторном добавлении.
   - Клик по карточке открывает детальное окно блюда с граммовкой, КБЖУ, бейджами остроты (`🌶️ Острое`, `🌶️🌶️ Огонь`) и выбором топпингов (двойной сыр чеддер, перчик халапеньо, порция гуакамоле, хрустящий бекон).

4. **Корзина и оформление заказа (Zero-Bug Checkout)**:
   - **Десктоп:** Удобная правая колонка со списком блюд, расчетом бесплатной доставки (прогресс-бар), выбором количества приборов и итоговой суммой.
   - **Мобильные:** Плавающая желтая кнопка `В корзине 2 товара • 650 ₽ ➔` внизу экрана.
   - **Чекаут за 1–2 шага:** Только имя, телефон с авто-маской `+7 (999) ...` и адрес доставки (без паролей и обязательных email).
   - **Надежная система оплаты:**
     - *При получении курьеру (наличные или терминал)* — моментальное и безотказное оформление.
     - *Онлайн картой / СБП* — защищенный симулятор эквайринга. При отмене или сбое корзина НЕ теряется, доступен переход на оплату при получении в 1 клик.
     - *Заказ через WhatsApp* — в 1 клик формирует готовое отформатированное сообщение со списком блюд, адресом и суммой прямо на номер ресторана `+7 (999) 650-55-76`.

5. **Живой трекер статуса заказа**:
   - Окно статуса в реальном времени с номером заказа (например, `#FB-7858`).
   - Таймлайн: *1. Принят рестораном ➔ 2. Готовим на открытой кухне 🌯 ➔ 3. Курьер в пути 🛵*.

## 🚀 Как запустить для показа клиенту

Проект полностью автономен и не требует сборки.

### Вариант 1 (простой запуск локального веб-сервера):
В папке проекта выполните в терминале:
```powershell
python -m http.server 8080
```
И откройте в браузере: `http://localhost:8080`

### Вариант 2:
Либо просто открыть файл `index.html` в любом современном браузере — логика приложения поддерживает автономный запуск.

## 🛡️ Сквозная верификация Playwright

Запуск тестов:
```powershell
python test_site.py
```
Проверяет:
- Полную загрузку страницы (0 ошибок в консоли браузера).
- Поиск по меню и фильтрацию.
- Открытие модального окна кастомизации блюда и выбор модификаторов.
- Добавление в корзину и динамический пересчет суммы.
- Оформление заказа и переход в трекер статуса.
- Мобильную версию (iPhone 14) с плавающей кнопкой корзины и мобильным чекаутом.
